# V3 — dirección editorial Chubut Web

Se tomaron del CSS original de Chubut Web la familia Instrument Serif + DM Sans, escala tipográfica editorial, cuadrícula, blancos amplios, tarjetas planas, navegación sin píldoras y separadores finos. Se conservaron los azules del Foro.

**Navbar:** se eliminó el hueco de 8 px entre menú y submenú (`top:100%`) que producía pérdida del hover. En dispositivos táctiles hay navegación expandida mediante el menú móvil.

La portada evita gráficos orbitales, tarjetas simbólicas y ornamentos artificiales. Contenidos, CMS, SQL, funciones y configuración Supabase se mantienen. Los estilos se fuerzan en CSS porque pueden existir valores de tema antiguos almacenados en el CMS.
