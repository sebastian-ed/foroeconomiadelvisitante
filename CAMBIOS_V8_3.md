# V8.3 — Corrección de tipografías

- Se corrigió la petición de Google Fonts: cada familia se descarga separadamente sin solicitar pesos incompatibles.
- Se reforzaron las reglas CSS para H1–H6, subtítulos, textos, artículos, navegación, botones y antetítulos.
- Se conserva la selección guardada en `theme` y las fuentes cargadas en Supabase Storage.
- Se corrigió el estilo de la vista previa editorial.
- Se actualizó el parámetro de versión del CSS y JS para minimizar problemas de caché.

Para aplicar cambios existentes, subir los archivos y recargar con Ctrl+Shift+R. En el CMS, confirmar los valores en Diseño y usar Publicar sitio. No requiere SQL.
