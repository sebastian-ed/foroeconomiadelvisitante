# V8.1 — Corrección de contraste del editor visual

El editor visual aplicaba fondo blanco a los textos enfocados pero heredaba color blanco de los títulos sobre fondos oscuros. Ahora los elementos editables enfocados utilizan fondo blanco, texto azul oscuro y cursor claramente visible, manteniendo la apariencia pública fuera del modo edición.

No requiere SQL ni modifica datos, CMS, fuentes ni funcionalidades.
