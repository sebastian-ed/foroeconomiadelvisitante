# V27 — editor de artículos y vista previa

- La vista previa importa el CSS público y muestra la imagen destacada solo en las tarjetas, no dentro del artículo.
- Las fotografías laterales ahora usan la misma composición flotante en el editor y en la web pública.
- Selector múltiple por casillas: mover grupo arriba, abajo o eliminar selección.
- Los controles de edición no se almacenan dentro de los artículos.
- Las vistas de Conocimiento reciben las publicaciones vigentes desde el CMS y consultan Supabase al iniciarse.
- Los bloques originales permanecen compatibles con versiones anteriores.

- Nueva ubicación «Junto al extracto · derecha»: permite una fotografía exclusiva del extracto, diferente de la imagen destacada del listado.
- Si ya hay imágenes repetidas guardadas como bloques distintos, se pueden seleccionar y eliminar por separado; la versión no borra contenidos históricos automáticamente.
