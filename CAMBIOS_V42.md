# V42 — Autoría independiente corregida

- Opción «Mostrar Escrito por» (activada por defecto) independiente de las biografías. Si se desactiva, la firma superior y la firma de las tarjetas no aparecen.
- Campo de firma vacío + visible: continúa apareciendo el nombre predeterminado del sitio. Con texto: usa exactamente el texto ingresado.
- Las fichas de autor adicionales se conservan al guardar aunque no tengan nombre, siempre que tengan biografía, profesión o fotografía.
- Se conservan tantas biografías como se incorporen; cada una controla su propia visibilidad y foto.
- Al reabrir la publicación se recuperan todas las fichas y el estado de firma visible/oculta.
- Sin cambios de base de datos. El ajuste de visibilidad se guarda como marcador HTML interno del contenido.

## Prueba recomendada
Crear dos biografías visibles, con foto, dejar la firma vacía y guardar. Reabrir y comprobar ambas. Luego desmarcar «Mostrar Escrito por», guardar y comprobar que las dos biografías permanecen visibles.
