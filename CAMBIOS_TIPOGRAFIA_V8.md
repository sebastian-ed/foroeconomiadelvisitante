# Tipografías V8

- Selectores independientes para títulos, subtítulos, texto, artículos, navegación, botones y antetítulos.
- Catálogo Google Fonts con familias serif y sans serif.
- Carga de fuentes propias WOFF2, WOFF, TTF, OTF a Supabase Storage desde Diseño.
- Vista de muestra de cada jerarquía y configuración publicada mediante el CMS habitual.
- El archivo de fuente debe permitir su uso web conforme a su licencia.
- Si Supabase rechaza un tipo MIME de fuente, agregarlo a los tipos permitidos del bucket `foro-media` en Storage.
- No cambiar datos sensibles de Supabase ni recrear el proyecto.

Antes de subir fuentes ejecutá `supabase/migration_v8_fonts.sql` en el SQL Editor de tu proyecto actual.
